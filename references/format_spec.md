# Formal Chinese Word Paper Format

## Requirements by Document Type

Follow the receiving institution's or journal's current instructions and the supplied template. Use the national standards and the fallback settings below to fill gaps.

- **Course report.** Follow the assignment's required sections and submission format. Check for a prescribed cover, automatic table of contents, and a requirement to start the body on a new page.
- **Journal manuscript.** Follow the journal's author instructions and use GB/T 7713.2-2022 as a general baseline. Check title, author and affiliation information, abstract, keywords, body, and references. Check the journal's requirements for multilingual front matter and supplementary material.
- **Thesis or dissertation.** Follow the degree-granting institution's template and consult GB/T 7713.1-2025. Check institution-specific front matter, pagination, contents, references, and any prescribed appendices or declarations.

## Fallback Word Settings

Use these settings when the target format leaves them open. GB/T 7713.2-2022 Appendix B gives an informative typography example with 10.5 pt SimSun body text and SimHei headings.

- Use A4 for a printable report. Use SimSun for Chinese body text, Times New Roman for Latin text and numerals, 12 pt body text, and 1.5 line spacing.
- Set body alignment, first-line indent, margins, and page numbering consistently with the document type and target template. If the template leaves body alignment open, keep the chosen alignment consistent. Right edges may vary naturally in left-aligned text.
- Use standard simplified Chinese in original Chinese prose. Preserve the language and script of verbatim quotations, source titles, proper names, and code where appropriate.
- Use black headings with a clear hierarchy. For a new course report, `1`, `1.1`, and `1.1.1` are practical numbering defaults. Use regular weight for headings and table headers by default when no target style specifies otherwise.

## Figures and Tables

- Number figures and tables in separate sequences, following any chapter-based numbering in the template. Place figure numbers and titles below the figure and table numbers and titles above the table.
- Include bilingual titles when the target asks for them. Use a three-line table when it meets the template and makes the data clear. Repeat table headings on continuation pages and follow the target's rules for continuation labels.
- Keep graphics legible at their placed size. Follow the target's format and resolution requirements. Use a sufficiently high-resolution raster source for photographs and keep diagrams and text sharp.
- Use standard units and symbols as required by the target. Use a space between the value and unit symbol where applicable, as in `20 mL`. Italicize statistical symbols such as *t* and *P* where appropriate.

## References

Use GB/T 7714-2025 unless the receiving institution, journal, or assignment specifies another edition or citation style. GB/T 7714-2025 took effect on 2026-07-01 and superseded GB/T 7714-2015.

- Use sequential numbering or author–year consistently, according to the submission requirements. Sequential numbering is the fallback for course reports. Assign `[n]` in order of first citation and reuse the same number when citing the source again. With author–year, keep matching author names and years between the text and the reference list.
- Use the format for the actual resource type. Preserve the source's original language and verify the author or institution, title, publication details, pagination or article number, and identifier against the resource.
- For a website or webpage that is itself the source, use `[EB/OL]` and record the actual access date and resource URL. Include the creation or last update date if available. Use the specific resource type for an online journal article, standard, report, dataset, or computer program. For software cited as an artifact, use the program type and record the version or commit when available.
- Reconcile in-text citations with the reference list. Verify every cited entry, follow the applicable rules for uncited reading material, and confirm that each number or author–year label resolves to the correct source.

### Reference Patterns

These patterns show fields and punctuation. Replace every placeholder with verified source data, omit inapplicable fields according to the standard, and follow its examples for other resource types.

```text
[1] 作者. 文章题名[J]. 刊名, 年, 卷(期): 页码或文章编号.
[2] 作者. 书名[M]. 版本. 出版地: 出版者, 年: 引文页码.
[3] 机构. 网页题名[EB/OL]. (创建或修改日期) [实际引用日期]. URL.
```
