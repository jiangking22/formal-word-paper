# Formal Chinese Word Paper Format

Apply this contract when creating or editing formal Chinese Word papers.

## Text And Layout

- Page size: use the user's template when available; otherwise use A4.
- Chinese font: SimSun (`宋体`).
- English and numeric font: Times New Roman.
- Body font size: 12 pt.
- Body line spacing: 1.5.
- Body paragraphs: black text, no random bold, no random color, no unexplained direct formatting.
- Language: Simplified Chinese. Convert or rewrite Traditional Chinese before delivery.

## Headings

- Use hierarchical numbering:
  - Level 1: `1`
  - Level 2: `1.1`
  - Level 3: `1.1.1`
- Headings are left aligned and flush left.
- Headings must be black.
- Do not use Word's blue theme heading, hyperlink, or title styles.
- Do not manually color or resize individual heading runs.

## Tables

- Use three-line tables where appropriate: top rule, header bottom rule, bottom rule.
- Number tables sequentially as `表1`, `表2`, etc.
- Put bilingual Chinese-English table titles above the table.
- Keep table data consistent with the正文.
- Avoid repeating the same information in both the table and surrounding prose unless necessary for interpretation.
- Use explicit column widths, repeating header rows for multi-page tables, and sufficient cell padding.

## Figures

- Use clear original images.
- Preferred image formats: JPG or TIFF.
- Target image resolution: at least 300 dpi when source material allows.
- Number figures sequentially as `图1`, `图2`, etc.
- Put bilingual Chinese-English figure titles below the figure.
- Ensure figure data, labels, and conclusions match the正文.

## Units And Statistics

- Use SI units and standard scientific notation, for example `mg/kg`, `mL`, `g/L`, `cm`, `mm`, `s`, `min`.
- Avoid nonstandard Chinese unit expressions such as `克/升`, `毫升`, `毫克/千克` in measured values.
- Italicize statistical symbols such as `t` and `P`.
- Prefer `P < 0.05` or `P = 0.032` with italic `P`.

## References

- Follow GB/T 7714-2015.
- Use sequential numeric citations and reference entries.
- Reference list entries should start with `[1]`, `[2]`, `[3]`.
- Example journal:

```text
[1] 张某某, 李某某. 信息科学进展[J]. 武汉大学学报·信息科学版, 2023, 48(5): 12-15.
```

- Example book:

```text
[2] 王某某. 信息科学原理[M]. 北京: 科学出版社, 2020: 45-50.
```

## Final QA Checklist

- No Traditional Chinese characters remain.
- No blue or theme-colored headings remain.
- No random bold text in body paragraphs.
- No direct formatting pollution in normal prose.
- Body font,字号, and line spacing are consistent.
- Headings use the required numbering hierarchy.
- Table captions appear above tables and are sequential.
- Figure captions appear below figures and are sequential.
- Units use SI forms.
- Statistical symbols are italicized.
- References follow GB/T 7714-2015 sequential numbering.
